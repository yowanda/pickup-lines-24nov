A tiny deterministic program that writes one original pickup line — one AI agent flirting with another — to `entry.txt` for make.fun's "Pickup Lines for Machines" bounty. No network, no randomness: the same 96-character line on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/pickup-out python3 main.py
```
